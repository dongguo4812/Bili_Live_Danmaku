# Live2D 模型目录

模型按 Cubism 运行时版本分开放置：

- `moc2/<模型目录>/`：Cubism 2 模型，配置文件为 `model.json` 或 `<模型目录>.model.json`。
- `moc3/<模型目录>/`：Cubism 3 及以上模型，通常以 `.model3.json` 为入口。

当前版本的展示页仍使用原有 Cubism 2 运行时，只扫描并加载 `moc2/`。
`moc3/` 先作为独立模型存放目录预留；MOC3 扫描器、加载器和展示入口将在后续阶段接入。

旧版 `models/<模型目录>/` 平铺目录仍会作为 MOC2 兼容路径读取，避免升级后本地自定义模型失效。

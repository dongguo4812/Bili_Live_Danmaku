# Live2D 模型目录

项目使用两套独立的模型目录和运行时，必须按模型格式放置资源：

- `moc2/<模型目录>/`：Cubism 2 模型，入口文件为 `model.json` 或 `<模型目录名>.model.json`。
- `moc3/<模型目录>/`：Cubism 3 及以上模型，通常以 `<模型目录名>.model3.json` 为入口。

完整展示页根据 `config/local/live2d.json` 中保存的运行时版本加载对应目录。MOC2 与 MOC3 的模型选择和模型偏好分别保存，切换版本不会覆盖另一版本的设置。

MOC2 默认模型 ID 配置为 `live_uu`；如果本机未安装该模型，请在展示页选择已安装模型，或将合法授权的模型放入 `moc2/`。MOC3 未配置默认模型时，会从可用模型中自动选择。

添加模型时，请确认模型配置引用的主体文件、贴图、动作、表情、物理和其他资源均存在。模型资源应具有合法使用授权；不要因为资源已放入仓库就推断其可以脱离原授权协议再分发。

# 普通配置目录

本目录只存放可公开的普通功能配置，例如直播间号、重连间隔、Live2D 模型偏好、语音设置、模块参数、冷却时间、浏览器路径、OBS 地址/端口/来源名称和日志保留天数。

**禁止存放：** B 站 Cookie、OBS 密码、访问令牌、API Key、Authorization 等任何可用于登录或授权的秘密。

- `config/*.json`：当前普通设置，可按需备份；不同模块配置分别保存在独立 JSON 文件中。
- `config/app.json`：服务设置和唯一的系统管理员 UID 列表。
- `credentials/`：敏感凭据，由 `CredentialStore` 或 B 站二维码登录模块管理；整个目录必须被 Git 忽略。
- `data/`：本地运行数据，包括 Chrome Profile、队列运行状态和综合展示布局。
- `logs/`：按日期生成的日志，自动脱敏并按配置清理。

当前版本只读取新的模块配置，不再提供旧根目录 JSON 或旧文本配置的自动迁移、兼容读取功能。OBS 密码必须通过凭据管理页面重新录入或更新；B 站登录通过二维码流程完成。

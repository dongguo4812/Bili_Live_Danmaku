# 普通配置目录

本目录只存放可公开的普通功能配置，例如直播间号、重连间隔、模块参数、冷却时间、浏览器路径、OBS 地址/端口/来源名称和日志保留天数。

**禁止存放：** B 站 Cookie、OBS 密码、访问令牌、API Key、Authorization 等任何可用于登录或授权的秘密。

- `config/*.json`：普通设置，可备份和编辑。
- `credentials/`：敏感凭据，由 `CredentialStore` 或 B 站二维码登录模块管理；整个目录必须被 Git 忽略。
- `data/`：本地运行数据，包括 Chrome Profile、管理员 UID 文件、队列运行状态和综合展示布局。
- `logs/`：按日期生成的日志，自动脱敏并按配置清理。

首次启动时会从旧根目录 `config.json` 一次性迁移普通设置；旧 `user_settings.json` 中最后确认的房间号、Live2D 和语音偏好会迁入对应模块配置。旧 OBS 明文密码和旧密码文件路径不会被迁移，必须在系统设置页重新录入密码。

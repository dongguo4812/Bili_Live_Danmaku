# 普通配置目录

本目录分为默认模板和本机运行配置。程序只读取并写入本机配置，默认模板由 Git 跟踪，用于首次启动初始化和补齐新增字段。

## 目录结构

- `config/default/*.json`：项目提供的默认配置模板，纳入 Git 管理；新用户首次运行时据此创建本机配置。
- `config/local/*.json`：当前电脑实际使用的配置，程序统一从这里读取和保存；由 `.gitignore` 忽略，不提交到 Git。
- `config/app.json`（旧版位置）：仅作为升级兼容来源；新版本不再从该位置保存配置。

首次运行时，程序会将默认模板初始化到 `config/local/`。如果检测到旧版根目录 `config/*.json`，会优先将旧配置迁入本机配置；本机已有值始终优先。以后默认模板增加配置项时，缺少的字段会自动补齐到本机配置，不覆盖已有设置。

## 配置职责

| 文件 | 用途 |
|---|---|
| `app.json` | 服务设置及唯一的系统管理员 UID 列表 |
| `live.json` | 直播间号与连接设置 |
| `live2d.json` | Live2D 运行时启用状态、模型与按模型保存的弹幕框布局偏好 |
| `danmaku.json` | 弹幕模块设置与空闲随机提示 |
| `voice.json` | 语音播报设置 |
| `music.json` | 歌曲模块普通设置 |
| `video.json` | 视频模块普通设置 |
| `obs.json` | OBS 地址、端口、超时和来源名称 |
| `logging.json` | 日志等级与保留天数 |

点歌和视频点播的粉丝牌配置统一使用布尔值：`true` 表示要求本直播间粉丝牌，`false` 表示不要求。新用户默认均为 `false`。旧版点歌配置的数字 `0/1` 会按原有含义转换（`0` 转为 `true`，`1` 转为 `false`）。

## 与配置目录分离的数据

- `credentials/`：B 站 Cookie、OBS 密码等敏感凭据，由凭据管理模块安全保存；不得放入普通配置或提交到 Git。
- `data/`：Chrome Profile、队列运行状态、综合展示布局等本机运行数据。
- `logs/`：日志文件，按保留策略清理。

普通配置同样禁止保存 Cookie、密码、访问令牌、API Key、Authorization 等秘密。OBS 密码必须通过凭据管理页面保存；B 站登录通过二维码流程完成。

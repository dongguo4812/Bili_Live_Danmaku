# 业务模块

业务模块按 Live2D、语音、歌曲和视频拆分。模块服务封装各自的业务状态、队列和资源生命周期；统一配置、事件分发和生命周期调度由 `core/` 中的基础设施负责。

- `ModuleManager` 统一管理各模块启动、暂停、恢复、关闭，以及直播断线后的暂停和重连恢复。
- 用户在接入中心的“功能启停控制”面板操作模块生命周期；模块详情页只保留队列、配置、试听等专属操作。
- Live2D 使用独立的启用/停用开关，不要求 B 站直播连接。
- 语音模块在首次完成 B 站 WebSocket 认证连接后自动启动；歌曲和视频模块每次应用启动后默认关闭，由用户手动启动。
- 直播断线时，歌曲、视频和语音模块暂停；重连后只恢复断线前处于运行状态且未被用户手动更改的模块。

歌曲与视频模块必须保持独立：任何一个模块的启动、暂停、恢复或关闭都不能改变另一个模块的状态或播放进度。业务模块不创建第二套 B 站登录凭据或 LiveDanmaku 连接。

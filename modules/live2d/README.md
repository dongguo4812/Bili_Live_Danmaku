# Live2D 模块

项目保留两套独立的模型运行时：

- MOC2：Cubism 2 运行时，模型位于 `models/moc2/<模型ID>/`，由 `static/js/live2d.min.js` 加载。
- MOC3：Cubism 5 R5 Core / Framework 运行时，模型位于 `models/moc3/<模型ID>/`，由独立的 MOC3 iframe/runtime 加载。

完整展示页 `/live2d/display` 根据已保存的运行时版本加载对应模型。两套版本的模型目录、模型选择、动作/表情和模型偏好相互隔离；版本切换不会把另一版本的设置覆盖。

模型能力检测会检查模型主体、贴图、动作、表情、物理配置、HitArea 映射和 TTS 嘴型参数。MOC3 支持模型动作、表情、快捷键和自定义触摸动作映射；功能是否可用仍取决于模型资源本身是否声明相应内容。

TTS 嘴型同步根据实际播放音频驱动模型参数。没有 LipSync 参数组且没有兼容嘴型参数的模型会被明确标记为不支持；这是模型能力限制，不是 MOC3 运行时故障。

Live2D 生命周期由接入中心统一控制，使用“启用/停用”单按钮切换；Live2D 展示运行不依赖 B 站直播连接。模型渲染由浏览器展示页执行，综合展示页通过嵌入完整展示页显示模型。

# B站直播弹幕助手（中文版）

[English](README.md) | **简体中文**

一个用于 B 站直播间的本地弹幕助手，支持二维码登录、直播间弹幕/礼物/醒目留言接收、Live2D 模型展示、Edge TTS 语音播报，以及 OBS 浏览器源自动控制。

## 功能概览

### B站连接

- 使用 B 站 WEB 二维码登录，不支持匿名连接。
- 登录成功后保存 Cookie；启动时和连接前都会检查登录凭据。
- 登录凭据失效时可重新扫码。
- 扫码登录完成后可继续连接直播间，无需再次扫码。
- 通过 LiveDanmaku WebSocket 接收直播间事件。
- 支持意外断线后自动重连；可在配置文件中调整重连行为和间隔。
- 管理页面只有在收到 B 站 WebSocket 验证成功事件后才显示连接成功。

### Live2D 与弹幕

- 使用 Live2D Cubism 2（MOC2）运行时渲染模型。
- 默认模型 ID：`live_uu`。
- 支持普通弹幕、礼物和醒目留言（SC）的展示。
- 弹幕以对话框形式显示，可调整位置、尺寸、字体、同时显示条数和显示时长。
- 页面背景保持透明，适合叠加到 OBS 场景中。
- 根据语音音量驱动 Live2D 嘴型。

### Edge TTS

- 普通弹幕、礼物、SC 分别提供独立播报开关。
- 可配置中文语音音色、语速、音量和最大等待队列长度。
- 可设置礼物最低金额门槛。
- 礼物和 SC 使用高优先级，普通弹幕使用低优先级。
- 当前正在播放的语音不会被新消息打断。
- 等待队列已满时，优先丢弃队列中最早的一条普通弹幕语音；若没有可丢弃的普通弹幕，则新语音不入队。
- 提供测试语音功能。

SC 播报示例：

- 有金额：`东郭老贼来了发来价值五十元的醒目留言：主播什么时候下播？`
- 无金额：`醒目留言，东郭老贼来了说：主播什么时候下播？`

## 运行环境

- Windows 10/11
- Python 3.10 或更高版本
- 可正常访问 B 站登录与直播 API 的网络环境
- OBS Studio（需要 OBS 浏览器源自动控制时）
- OBS WebSocket 服务器（OBS Studio 内置，默认端口为 `4455`）

项目依赖见 [requirements.txt](requirements.txt)，其中包含 Flask、requests、bilibili-api-python、websocket-client、qrcode 和 edge-tts 等。

## 安装与启动

1. 下载或克隆本仓库。
2. 确保已安装 Python 3.10 或更高版本，并能通过 `py -3` 调用。
3. 双击项目目录中的 `start.bat`。
4. 首次启动时，脚本会创建本地 `.venv` 虚拟环境并安装依赖。
5. 打开管理页面：

   `http://127.0.0.1:8768/`

6. OBS Live2D 透明展示页面：

   `http://127.0.0.1:8768/live2d/display`

使用期间请保持启动程序的控制台窗口运行。正常停止时，可在控制台按 `Ctrl+C`；也可以使用窗口关闭按钮退出。程序正常退出时会尝试清理 OBS 展示来源状态。

### 手动启动

在项目根目录打开 PowerShell：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

## B站登录与直播间连接

1. 在管理页面填写直播间房间号，点击“保存房间号”。直播间号保存在 `config/live.json`。
2. 点击“扫码登录”，使用 B 站手机客户端扫描二维码并确认登录。
3. 登录成功后，程序从 B 站二维码登录流程取得 Cookie，并保存到本地凭据文件。
4. 程序启动时会检查已有登录凭据；连接直播间前也会再次验证。
5. 如果凭据无效或已过期，请重新扫码登录。
6. 点击“连接直播间”。只有收到 WebSocket 验证成功事件后，页面才会显示已连接。
7. 连接异常时，程序会按配置尝试自动重连。需要停止时点击“断开连接”。

二维码登录使用 B 站 WEB QR 登录接口。当前登录流程会跟进成功扫码后返回的跨域 ticket URL，以接收响应头中的登录 Cookie；不会仅凭二维码扫描成功就判定登录成功，而是继续验证已登录状态。

## Live2D 模型

默认模型 ID 为 `live_uu`，模型目录：

```text
models/
└── live_uu/
    └── model.json
```

项目支持模型配置文件名为 `model.json`，也兼容 `<模型目录名>.model.json`。Cubism 2 运行时文件：

```text
static/js/live2d.min.js
```

展示控制脚本：

```text
static/js/display.js
```

模型资源需要由使用者自行放入对应目录，并确保具有合法使用授权；模型资源不会随项目自动分发。添加模型时，请将模型目录放入 `models/<模型ID>/`，并在模型配置中确认引用的纹理、动作和其他资源路径正确。

程序会检查模型配置引用的文件，并在 WebGL 画布实际检测到模型绘制像素后才报告运行时加载成功。渲染缓冲区会根据展示区域尺寸和设备像素比调整（设备像素比最高按 2 处理），页面背景保持透明。

### OBS 浏览器源地址

在 OBS 中添加“浏览器”来源，URL 填写：

```text
http://127.0.0.1:8768/live2d/display
```

建议浏览器源分辨率与 OBS 实际输出画布一致，例如 1920×1080，避免低分辨率拉伸造成模糊。

## 弹幕对话框

在展示页面左上角点击“设置”，可调整：

- 模型：选择已安装的 Live2D 模型。
- 模型大小、水平位置和垂直位置。
- 弹幕对话框水平位置、底部位置、宽度和最大高度。
- 弹幕字体大小。
- 同时显示的弹幕条数。
- 每条弹幕的显示时长。

滑块调整会即时预览；点击设置面板底部的“保存设置”后才会保存。每个 Live2D 模型分别保存自己的模型变换和弹幕对话框设置。

## 语音播报（Edge TTS）

在展示页面设置面板的“Edge TTS 语音播报”区域进行配置：

- 普通弹幕、礼物、醒目留言（SC）开关。
- 语音音色。
- 语速和音量。
- 最大等待队列长度。
- 礼物最低金额。

语音由 Edge TTS 在线合成，合成后的 MP3 文件暂存在系统临时目录 `bili_live_danmaku_tts`。程序在后续合成请求时清理超过一小时的旧文件。

展示页会自动尝试初始化和恢复 Web Audio，并在直播连接后处理语音队列。浏览器或 OBS 的自动播放策略可能影响音频启动；如果音频没有播放，请检查 OBS 浏览器源和浏览器的音频/自动播放设置。页面保留“测试语音”按钮，便于诊断音频输出与嘴型同步。

## OBS 配置与自动控制

程序可通过 OBS WebSocket v5 自动控制展示页面对应的浏览器源：

- B 站直播间 WebSocket 真实连接成功后，程序自动查找 URL 与当前服务地址及 `/live2d/display` 路径匹配的浏览器源。
- 自动刷新并显示匹配的场景来源。
- OBS 尚未启动、WebSocket 暂时不可用或尚未找到来源时，后台每 3 秒重试。
- 正常退出程序时，尝试隐藏匹配的展示来源。
- 会遍历场景及嵌套分组中的场景项目，处理匹配浏览器源对应的场景项。

OBS WebSocket 普通配置保存在 `config/obs.json`，包含地址、端口、超时和来源名称。密码统一在凭据管理页录入，保存在 `credentials/obs.json`；Windows 使用当前 Windows 用户上下文的 DPAPI 加密，页面不会回显密码原文。非 Windows 开发环境使用仅本机文件权限保护的存储格式，不应将该环境的凭据文件复制到其他设备；正式 Windows 使用时应由目标 Windows 用户重新保存凭据。

系统设置页面：`http://127.0.0.1:8768/settings`；统一凭据入口：`http://127.0.0.1:8768/credentials`。请在 OBS 的“工具 → WebSocket 服务器设置”中启用 WebSocket 服务器，并确认地址、端口和来源名称正确。

## 本地数据与安全

项目将数据分为三类：

- `config/`：普通功能配置，例如直播间号、模型设置、语音设置、歌曲/视频参数和 OBS 地址端口。
- `credentials/`：敏感凭据，例如 B 站 Cookie、OBS 密码和第三方 API Key。Windows 下使用 DPAPI 保护。
- `data/`：运行数据，例如歌曲/视频队列缓存、Chrome Profile 和综合展示布局。
- `logs/`：运行日志，不得包含 Cookie、密码或 Token。

当前版本不再读取或迁移旧版 `user_settings.json`、根目录 `config.json`、`room_config.txt`、`obs_config.txt` 或独立管理员 UID 文本文件。请直接维护 `config/` 中的模块配置；直播间号位于 `config/live.json`，Live2D 模型和展示偏好位于 `config/live2d.json`，语音播报偏好位于 `config/voice.json`，OBS 普通设置位于 `config/obs.json`。系统管理员 UID 只保存在 `config/app.json`。OBS 密码和 B 站 Cookie 分别保存在 `credentials/obs.json`、`credentials/bilibili.json`，不要把 `credentials/` 上传到 GitHub。

## 统一模块与综合展示

管理入口：`http://127.0.0.1:8768/`

侧边导航包含综合展示、接入中心、Live2D、语音播报、歌曲点播/设置、视频点播/设置、系统设置和凭据管理。

- 歌曲和视频模块相互独立，启动、暂停、恢复和关闭不会影响对方。
- 每次主程序启动时，歌曲和视频模块默认关闭。
- 歌曲模块保留四平台搜索匹配、全平台精确歌手优先、音源 ID 入队保存、5 秒播放核验失败回退、队列、粉丝牌验证、管理员切歌和点歌开关。
- 视频模块保留 Chrome/Selenium 播放、BV 校验、队列、播放结束监控和 OBS 来源显隐；网页全屏只在确认视频进度后尝试 W；视频暂停/关闭不会控制洛雪。
- 歌曲设置页：`/music/settings`；视频设置页：`/video/settings`。修改模块配置前需要先关闭对应模块。
- Live2D 和语音模块接入统一生命周期；直播断线时暂停互动，重连后按断线前状态恢复。
- 系统管理员 UID 在系统设置页 `/settings` 统一配置，歌曲和视频模块共用；不再分别维护 `data/music/uid.txt`、`data/video/uid.txt`。
- 独立透明展示页面：Live2D 完整展示 `/live2d/display`（包含 Live2D、弹幕和 TTS）、MOC2 单独展示 `/live2d/moc2/display`、弹幕 `/danmaku/display`、语音 `/voice/display`、歌曲队列 `/music/display`、视频队列 `/video/display`、歌曲信息组件 `/music/widget`
- Live2D 设置 API 统一使用 `/api/live2d/` 前缀。
- 综合展示布局编辑页：`/dashboard`。可添加/移除模块、拖动位置、调整大小，并手动保存；支持多套布局的创建、复制、重命名、删除和设为默认。
- OBS 默认综合展示地址：`/display/combined`；指定布局使用 `/display/combined/<布局ID>`，不同 OBS 场景可分别绑定不同布局。视频模块只显示当前播放、下一条、待播队列和通知，不嵌入视频画面。

GitHub Actions 会在 Ubuntu 环境执行 Python 编译、配置与凭据回归测试及离线测试，并在 Windows 环境额外执行真实 DPAPI 加解密和配置退役回归测试。CI 通过不等于已完成所有设备上的人工联调；歌曲和视频模块仍需结合洛雪音乐、Chrome、OBS WebSocket 和实际直播间环境进行本机验证。

## 常见问题

### 管理页面提示未登录

请重新点击“扫码登录”，使用 B 站手机客户端完成扫码确认。二维码扫描完成不等于登录验证完成；请等待页面显示登录成功。

### 登录成功，但直播间没有显示已连接

请确认房间号正确，并等待 WebSocket 完成认证。页面只有在收到验证成功事件后才会显示连接成功。可检查控制台日志和网络连接状态。

### Live2D 模型没有显示

确认 `models/live_uu/` 中存在模型配置文件及其引用的纹理等资源；再检查浏览器控制台是否有资源加载错误或 WebGL 错误。模型文件需要自行提供并具有合法授权。

### OBS 没有自动显示 Live2D

确认 OBS 正在运行、OBS WebSocket 服务器已启用、地址和端口正确、密码文件内容正确，并确认浏览器源 URL 指向当前程序的 `/live2d/display` 页面。自动显示以 B 站直播间 WebSocket 连接成功为触发条件。

### OBS 没有语音

确认 Edge TTS 网络合成正常，TTS 开关已开启，礼物金额达到设置门槛，并检查 OBS 浏览器源的音频/自动播放策略。可使用“测试语音”按钮检查音频输出。嘴型同步依赖展示页实际播放的音频。

### 某些弹幕没有显示或播报

程序只能处理 B 站实际推送到直播间 WebSocket 的事件。如果弹幕未通过 B 站审核，或未出现在 B 站原生聊天列表中，机器人也无法接收到该弹幕。
